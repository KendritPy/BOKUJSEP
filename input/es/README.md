# ISO española para runtime

Aplica por tu cuenta el parche oficial v1.0 de GriffithVIII/TraduSquare a una copia de tu ISO japonesa limpia y coloca aquí la imagen resultante con el nombre:

```text
Boku_ES.iso
```

SHA-256 esperado:
`3F3ED57C390684F774432B689EA94DF9C0EA5641D2ED907A3EE03BF1F69EE9C8`.

El instalador no descarga el parche de traducción. Puedes obtenerlo desde la [página oficial de TraduSquare](https://tradusquare.es/proyectos/boku-no-natsuyasumi/).
