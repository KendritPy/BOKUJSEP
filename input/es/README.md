# Spanish runtime ISO

Independently apply the official GriffithVIII/TraduSquare Spanish v1.0 patch
to your own clean Japanese dump, then place the resulting image here as:

```text
Boku_ES.iso
```

Expected SHA-256:
`3F3ED57C390684F774432B689EA94DF9C0EA5641D2ED907A3EE03BF1F69EE9C8`.

The installer does not download the translation patch. Do not distribute the
patched ISO; it is ignored by Git.
